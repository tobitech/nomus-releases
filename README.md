# Maestro Releases

Official releases for **Maestro** — a macOS agent.

## Download

Check the [Releases](https://github.com/tobitech/maestro-releases/releases) page for the latest version.

## Installation

1. Download the latest `.dmg` from [Releases](https://github.com/tobitech/maestro-releases/releases)
2. Open the `.dmg` and drag **Maestro** to your Applications folder
3. Launch Maestro from Applications

## Requirements

- macOS 26 (Tahoe) or later
